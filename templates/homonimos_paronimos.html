🎯 Diferencia en 1 minuto - Nivel Secundaria

HOMÓNIMOS: Se escriben IGUAL o suenan IGUAL pero significan distinto

  • Homógrafas: Se escriben igual: banco (sentarse) / banco (dinero)
  • Homófonas: Suenan igual: hola / ola, baca / vaca

PARÓNIMOS: Se escriben PARECIDO y por eso te confunden

  • Ej: aptitud / actitud, absorber / absolver
  • No suenan igual, pero se parecen mucho
REGLA DE ORO EXANI: Si duda es con b/v, h/no h, ll/y, s/c/z = HOMÓFONA. Si se parece pero cambia 1-2 letras internas = PARÓNIMA

1. HOMÓFONAS QUE SIEMPRE SALEN (con b/v - h - ll/y)

Con H y sin H

  • Hola (saludo) / Ola (del mar)
  • Hora (tiempo) / Ora (de orar)
  • Hecho (de hacer) / Echo (de echar) -> “He hecho la tarea” / “Echo la basura”
  • Hasta (preposición) / Asta (cuerno o bandera)
  • Hay (haber) / Ay (dolor) / Ahí (lugar) -> EL TRÍO MORTAL

Con B y V

  • Vaca (animal) / Baca (portaequipaje del coche)
  • Bello (hermoso) / Vello (pelito)
  • Botar (tirar) / Votar (elecciones) -> ESTA SALE SIEMPRE
  • Tuvo (de tener) / Tubo (de plástico)
  • Revelar (mostrar) / Rebelar (sublevarse)

Con LL / Y / S / C

  • Rallar (queso) / Rayar (línea)
  • Cayo (isla) / Cayó (de caer) / Callo (del pie) / Calló (de callar) -> EL COMBO MORTAL
  • Casa (hogar) / Caza (de cazar)
  • Cocer (cocinar) / Coser (ropa)
  • Vaya (ir) / Valla (anuncio) / Baya (fruto)

2. PARÓNIMOS - LAS 10 TRAMPAS MORTALES

Estas te las ponen en texto y si no sabes, eliges mal el sinónimo.

1. APTITUD ≠ ACTITUD
Aptitud = capacidad (es apto para matemáticas)
Actitud = comportamiento (mala actitud)

2. ABSORBER ≠ ABSOLVER
Absorber = chupar (esponja absorbe agua)
Absolver = perdonar (juez absuelve al inocente)

3. INFLIGIR ≠ INFRINGIR
Infligir = causar daño (infligir dolor)
Infringir = violar ley (infringir la norma) -> SALE MUCHÍSIMO

4. PREVER ≠ PROVEER
Prever = anticipar (prever el futuro)
Proveer = dar, suministrar (proveer alimentos)

5. ESPECIA ≠ ESPECIE
Especia = condimento (pimienta)
Especie = tipo (especie animal)

6. AFECTO ≠ EFECTO
Afecto = cariño
Efecto = consecuencia

7. ADOLESCER ≠ ADOLECER
Adolescer = carecer (adolece de recursos)
Ojo: Adolescente no tiene nada que ver jaja

3. TRUCO PARA NO FALLAR EN EXAMEN

  • 1. Lee toda la oración, no solo la palabra
  • 2. Si ves “botar/votar” piensa: ¿habla de elecciones o de basura?
  • 3. “Hecho/Echo”: ¿puedes poner “ha hecho”? si sí, es con H
  • 4. Para parónimos: cambia la palabra por su definición y ve si tiene sentido
Ej: “El juez va a absolver/absorber al acusado” -> ¿Chupar al acusado? No. ¿Perdonarlo? Sí. Entonces es ABSOLVER

🎓 Nivel Preparatoria: Lo que te ponen en EXANI-II

1. Homonimia vs Polisemia

¿Qué es?¿Origen?Ejemplo
HomonimiaOrigen diferente, coincidenciaCola (pegamento / de animal)
PolisemiaMismo origen, varios sentidosBanco (asiento / institución, ambos de “sentarse”)

⚠️ En EXANI-II te preguntan: ¿Es homónimo o polisémico? Si los significados no tienen nada que ver, es homónimo. Si sí se relacionan, es polisemia.

2. Parónimos que solo salen en Prepa

  • Perjuicio ≠ Prejuicio: Perjuicio = daño / Prejuicio = juzgar antes de conocer
  • Eminente ≠ Inminente: Eminente = destacado / Inminente = que está por pasar
  • Acceder ≠ Exceder: Acceder = aceptar / Exceder = pasarse del límite
  • Consciente ≠ Consiente: Consciente = darse cuenta / Consiente = permite
  • Especular ≠ Especular: Cuidado, es homógrafa: adivinar / reflejar como espejo

3. Cómo se pregunta en EXANI-II

  • “Completa con la palabra correcta: Voy a ___ mi voto” → Votar, no botar.
  • “¿Qué tipo de relación hay entre hola / ola?” → Homófonas.
  • “¿Cuál es el parónimo de aptitud?” → Actitud.
  • “En el texto, la palabra X está mal usada, ¿por cuál la cambias?” → Busca su parónimo / homófona correcta.
