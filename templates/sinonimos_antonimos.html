📚 Definiciones en 30 seg - Nivel Secundaria

SINÓNIMO

  • Mismo significado (o muy parecido): casa = hogar, rápido = veloz
  • Tipos: Totales (fallecer=morir) / Parciales (alegre=contento pero no siempre igual)
  • ¿Para qué sirven? Para no repetir la misma palabra 10 veces en tu texto.

ANTÓNIMO

  • Significado opuesto: alto ≠ bajo, amor ≠ odio
  • Tipos clave EXANI:
  • Graduales: frío - tibio - caliente (puede haber punto medio)
  • Complementarios: vivo / muerto, soltero / casado (no hay punto medio)
  • Recíprocos: comprar / vender, dar / recibir
TRUCO EXANI #1: Nunca busques sinónimo perfecto, busca el que MEJOR quede en la oración. Contexto > diccionario.

1. CÓMO ATACAR SINÓNIMOS EN EXAMEN

Paso 1: Sustituye en la frase

  • Frase: “El alumno tuvo una actitud arrogante”
  • Opciones: a) humilde b) altiva c) amable
  • Prueba: “actitud humilde” no, “amable” no cuadra, “altiva” sí = RESPUESTA

Paso 2: Nivel de formalidad

  • EXANI te pone trampas: enojado = iracundo (formal) / encabronado (coloquial)
  • En examen siempre elige el formal si ambos significan lo mismo

Lista corta de sinónimos que SIEMPRE salen

  • Falacia = engaño, mentira
  • Efímero = pasajero, fugaz
  • Lacónico = breve, conciso
  • Veraz = verdadero, sincero
  • Inocuo = inofensivo
  • Prístino = puro, limpio, original
  • Insólito = raro, extraño
  • Perenne = eterno, duradero

2. CÓMO ATACAR ANTÓNIMOS

Truco del prefijo

  • Muchos antónimos se hacen con prefijos: posible -> IMposible, hacer -> DEShacer
  • Prefijos EXANI: in-, im-, des-, dis-, a-, anti-
  • Ej: legal / ilegal, moral / amoral, simétrico / asimétrico

Lista de antónimos tramposos

  • Probo = honesto / Ímprobo = deshonesto (no probó jaja)
  • Venial = leve / Mortal
  • Exógeno = de fuera / Endógeno = de dentro
  • Remoto = lejano / Próximo = cercano
  • Mitigar = suavizar / Exacerbar = empeorar
  • Opaco = no transparente / Diáfano = transparente
TRUCO #2: Si no sabes el significado, busca la raíz. “Bene” = bueno (benévolo) antónimo malevolo

3. PARÓNIMOS - LA TRAMPA MORTAL DE EXANI

Parecen sinónimos pero NO lo son. Se escriben parecido.

  • Aptitud ≠ Actitud: Aptitud = capacidad / Actitud = forma de ser
  • Absolver ≠ Absorber: Absolver = perdonar / Absorber = chupar
  • Infligir ≠ Infringir: Infligir = causar daño / Infringir = romper ley
  • Especia ≠ Especie: Especia = condimento / Especie = clase
  • Prever ≠ Proveer: Prever = anticipar / Proveer = suministrar
  • Afecto ≠ Efecto: Afecto = cariño / Efecto = resultado
  • Espiar ≠ Expiar: Espiar = vigilar / Expiar = pagar una culpa

🎓 Nivel Preparatoria: Lo que te ponen en EXANI-II

1. Homónimos - Se escriben / suenan igual, significan diferente

  • Homógrafas: Se escriben igual. Ej: Banco (asiento / institución), Vela (de barco / de cumpleaños)
  • Homófonas: Suenan igual, se escriben diferente. Ej: Tuvo (tener) / Tubo (objeto), Votar / Botar
  • En EXANI te ponen: “¿Qué tipo de relación hay entre tuvo / tubo?” → Homófonas.

2. Polisemia - Una palabra, varios significados

  • Cresta: Parte del gallo / Cumbre de la ola / Parte superior del cerro
  • Diferencia con homónimo: Polisemia tiene el MISMO origen. Homónimo tiene origen diferente.

3. Campo semántico

  • Grupo de palabras que comparten tema. Ej: Cocina: sartén, olla, cuchara, estufa.
  • En EXANI: “¿Cuál palabra NO pertenece al campo semántico?” → Elimina la que no es del tema.

4. Cómo se pregunta en EXANI-II

  • “Sinónimo de X en el contexto...” → No es diccionario, es el que encaja en esa oración.
  • “Antónimo de X...” → Cuidado, a veces el antónimo cambia si la palabra es polisémica.
  • “Término excluido” → Te dan 5 palabras, 4 son sinónimas / del mismo campo, 1 no. Esa es la respuesta.
